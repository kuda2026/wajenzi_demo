# Plant or Wait Simulator

Interactive soil-probe simulator for the Wajenzi demo.

## Launch the notebook

Open the notebook in Binder:

[Launch Plant or Wait Simulator](https://mybinder.org/v2/gh/kuda2026/wajenzi_demo/main?filepath=Plant_or_Wait_Simulator.ipynb)

Binder starts a temporary Jupyter environment in the browser. Click **Run All**, then use the simulator controls. No local installation is required.

## Run locally

Install the dependencies and open `Plant_or_Wait_Simulator.ipynb` in Jupyter or VS Code:

```bash
pip install -r requirements.txt
jupyter notebook
```
